# Бот «Призыва Нет» — самостоятельный проект

## Файлы
- `bot.py` — весь код бота.
- `requirements.txt` — необходимые Python-зависимости.
- `.env.example` — пример переменных окружения (сам `.env` не обязателен).
- `README.md` — эта инструкция.

## Важно про настройки
Этот проект **не использует `python-dotenv`**. Токен и ID задаются через переменные окружения в панели хостинга.
Если хостинг позволяет задать переменные окружения, создайте:
- `BOT_TOKEN` — токен от BotFather;
- `ADMIN_ID` — числовой Telegram ID администратора.

Если хостинг запускает приложение из файлов, настройте его на установку зависимостей из `requirements.txt` и запуск `python bot.py`.

## Установка
```bash
python -m pip install -r requirements.txt
python bot.py
```

Если хостинг использует поле «Start command», укажите:
```bash
python bot.py
```

## База данных
`priziv_bot.db` создаётся автоматически рядом с `bot.py`. Убедитесь, что у приложения есть права записи в эту папку и что диск хостинга постоянный (не ephemeral), иначе база может исчезнуть после перезапуска/пересборки.

## Что есть
- пользовательское меню, профиль, создание и просмотр обращений;
- приватная передача сообщений администратору через бота;
- кабинет администратора: обращения, карточки пользователей, ответы, закрытие тикетов;
- отправка сообщения пользователю;
- напоминания по расписанию;
- шаблоны и статистика;
- SQLite-история сообщений;
- проверка прав администратора и кнопки возврата в основных разделах.

## Важное ограничение кнопок
Telegram Bot API не позволяет задавать произвольный цвет фона стандартным inline-кнопкам. Красно-белый дизайн с настоящими цветными заливками требует отдельного Telegram Mini App на HTML/CSS. В этом проекте используются стандартные inline-кнопки с текстом и эмодзи.

## Безопасность
- Не публикуйте токен.
- Задайте корректный `ADMIN_ID`.
- Для реального использования настройте резервное копирование SQLite и часовой пояс хостинга.
